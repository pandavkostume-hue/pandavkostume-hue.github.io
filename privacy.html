Политика конфиденциальности

Приложение «Panda Chat Bridge» · действует с 9 ноября 2026 г. · на главную

Что это за приложение

Panda Chat Bridge — программа для трансляций канала PANDA (Руслан) на YouTube и Twitch. Она работает только на компьютере владельца канала и используется только им. Это не публичный сервис: другие люди её не устанавливают и не входят в неё своими аккаунтами.

Какие данные использует приложение

С разрешения владельца канала (вход через Google) приложение через YouTube API Services получает доступ к его каналу YouTube и использует:

  • список текущих трансляций канала и их настройки доступа — чтобы найти идущий эфир и сделать его открытым;
  • сообщения чата трансляций — чтобы показать их владельцу в программе OBS;
  • статистику эфира и канала — число зрителей, лайков и подписчиков;
  • отправку сообщений в чат и модерацию (удаление сообщения, временный или постоянный бан) — только когда владелец канала сам нажимает соответствующую кнопку.

Где хранятся данные

Все данные обрабатываются и хранятся только на компьютере владельца канала. Ключ доступа к YouTube хранится в локальном файле на этом компьютере. Приложение не передаёт данные третьим лицам, не продаёт их, не использует для рекламы и не отправляет ни на какие серверы, кроме серверов Google/YouTube (и Twitch — для чата Twitch), необходимых для работы функций выше.

Ограниченное использование

Использование и передача информации, полученной из API Google, в другие приложения соответствуют Политике в отношении данных пользователей сервисов API Google, включая требования ограниченного использования (Limited Use).

Как отозвать доступ

Доступ можно в любой момент отозвать на странице myaccount.google.com/permissions. После этого приложение перестанет получать данные YouTube. Локальные файлы удаляются вместе с программой.

Сервисы YouTube

Приложение использует YouTube API Services. Используя его, вы соглашаетесь с Условиями использования YouTube. См. также Политику конфиденциальности Google.

Privacy Policy

“Panda Chat Bridge” application · effective November 9, 2026

About the application

Panda Chat Bridge is a live-streaming helper for the PANDA (Ruslan) channel on YouTube and Twitch. It runs only on the channel owner's own computer and is used only by the channel owner. It is not a public service: no other people install it or sign in to it.

Data the application uses

With the channel owner's permission (Google sign-in), the application uses YouTube API Services to access the owner's YouTube channel and uses:

  • the channel's current live broadcasts and their privacy settings — to find the active stream and make it public;
  • live chat messages of those broadcasts — to display them to the owner inside OBS;
  • stream and channel statistics — viewer, like and subscriber counts;
  • posting chat messages and moderation (deleting a message, temporary or permanent ban) — only when the channel owner presses the corresponding button.

Data storage

All data is processed and stored only on the channel owner's computer. The YouTube access token is stored in a local file on that computer. The application does not share data with third parties, does not sell it, does not use it for advertising, and does not send it to any servers other than Google/YouTube (and Twitch, for Twitch chat) as required for the features above.

Limited Use

Panda Chat Bridge's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. After that the application can no longer receive YouTube data. Local files are removed together with the program.

YouTube API Services

This application uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy.
